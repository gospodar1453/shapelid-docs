---
title: "PayTR"
description: "Marketplace payment infrastructure with escrow and card tokenization"
---

PayTR Direct API handles all payment operations on Shapelid.

## Features

- **Marketplace split payments** — Customer pays Shapelid, manufacturer receives net after commission
- **Escrow** — Funds held until order completion/QC approval
- **Card tokenization** — Saved cards for repeat customers
- **Installments** — Taksit options for Turkish market
- **Recurring** — Subscription support for manufacturer plans

## Configuration

| Parameter | Description |
|-----------|-------------|
| merchant_id | PayTR merchant ID |
| merchant_key | PayTR merchant key |
| merchant_salt | PayTR merchant salt |

## Payment Flow

1. Customer places order on Client Portal
2. PayTR token generated with marketplace split parameters
3. Customer completes payment (credit card / installment)
4. Funds held in escrow
5. Manufacturer completes production + QC
6. Customer approves → escrow release to manufacturer
