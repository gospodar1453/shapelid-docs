The Shapelid Kernel API gives you programmatic access to the same geometric analysis and pricing engine that powers the Shapelid client portal. Upload a CAD file, specify a technology and material, and receive a full cost breakdown in milliseconds — without any manual steps. You can also retrieve available material and configuration options, run batch nesting optimisations for powder-bed fusion technologies, and submit calibration data to improve pricing accuracy over time.

---

## Base URL

All requests are made to:

```
https://shapelid-kernel-production.up.railway.app
```

**Current version:** v3.1.0

---

## Endpoints

The following endpoints are available:

| Endpoint | Method | Description |
|---|---|---|
| `/analyze` | POST | Upload a CAD file and receive an instant pricing breakdown with geometric analysis |
| `/options` | GET | List all valid materials, finishes, resolutions, and tolerances for a given technology |
| `/nest` | POST | Submit multiple parts for batch nesting optimisation; returns consolidated pricing for SLS and MJF builds |
| `/calibrate` | POST | Submit actual vs. predicted cost data to improve pricing accuracy via exponential smoothing |

---

## Authentication

The Kernel API is currently **open for read operations** — `GET /options` requires no authentication. Write and analysis endpoints (`POST /analyze`, `POST /nest`, `POST /calibrate`) are rate-limited by IP. If you are integrating the API into a production application and need a dedicated API key with higher rate limits, contact [destek@shapelid.com](mailto:destek@shapelid.com) with a description of your use case.

  The API's interactive documentation is auto-generated by FastAPI and available at [https://shapelid-kernel-production.up.railway.app/docs](https://shapelid-kernel-production.up.railway.app/docs). You can test all endpoints directly from the browser without writing any code.

## Quick Start

The following example uploads a local STL file and requests an FDM pricing quote using standard PLA:

```bash
curl -X POST https://shapelid-kernel-production.up.railway.app/analyze \
  -F "file=@my_part.stl" \
  -F "technology=fdm" \
  -F "material=fdm_pla" \
  -F "quantity=1" \
  -F "mode=simple"
```

A successful response looks like:

```json
{
  "technology": "fdm",
  "material": "fdm_pla",
  "quantity": 1,
  "volume_cm3": 12.5,
  "surface_area_cm2": 85.3,
  "print_time_min": 42,
  "breakdown": {
    "material_cost": 0.31,
    "machine_cost": 1.40,
    "setup_cost": 2.00,
    "overhead": 0.84,
    "subtotal": 4.55
  },
  "unit_price": 6.32,
  "total_price": 6.32,
  "manual_quote": false,
  "currency": "USD"
}
```

If the part triggers any manual-quote conditions (high quantity, excessive overhangs, thin walls, complex channels, volume exceeding build envelope, certification requirements, or multi-part assemblies), `manual_quote` is set to `true` and the response includes a `quote_triggers` array explaining why.

## Supported Technologies

Pass one of the following string values as the `technology` parameter in `/analyze` and `/nest` requests:

| Value | Technology |
|---|---|
| `fdm` | Fused Deposition Modelling |
| `sla` | Stereolithography |
| `sls` | Selective Laser Sintering |
| `mjf` | Multi Jet Fusion |
| `dmls` | Direct Metal Laser Sintering |
| `polyjet` | Polyjet / Material Jetting |
| `cnc_turning` | CNC Turning |
| `cnc_milling` | CNC Milling |
| `edm` | Electrical Discharge Machining |
| `laser_cutting` | Laser Cutting |
| `bending` | Sheet Metal Bending |

Use `GET /options?technology=<value>` to retrieve the full list of valid materials, finishes, resolutions, and tolerances for each technology before calling `/analyze`.

## Accepted File Formats

The `/analyze` and `/nest` endpoints accept the following CAD and mesh file formats as multipart form uploads:

- **STL** — recommended for additive manufacturing (FDM, SLA, SLS, MJF, DMLS, Polyjet)
- **OBJ** — mesh format suitable for most additive processes
- **GLTF** — supports assemblies and textured geometry
- **STEP** — preferred for CNC processes (Turning, Milling, EDM); preserves exact geometry
- **IGES** — solid-model format accepted for CNC and hybrid workflows
- **DXF** — 2D profile format required for Laser Cutting and Bending

## Rate Limits & Usage Notes

- **Unauthenticated requests** are limited to **60 requests per minute** per IP address for `POST` endpoints and **120 requests per minute** for `GET` endpoints.
- File uploads to `/analyze` and `/nest` are limited to **50 MB** per request.
- The `/calibrate` endpoint updates pricing factors in real time but requires a minimum of **3 calibration records** for a given technology-material pair before factors are activated in the pricing engine.
- Calibration factors are clamped to the range **[0.5, 2.0]** to prevent runaway adjustments. A weekly automated recalibration run executes every Monday at 02:00 Istanbul time.
- For sustained integration workloads above the unauthenticated limits, contact [destek@shapelid.com](mailto:destek@shapelid.com) to request a dedicated API key.
