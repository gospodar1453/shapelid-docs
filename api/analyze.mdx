---
title: "POST /analyze"
description: "Analyze a CAD file and return pricing breakdown"
---

## Request

```bash
curl -X POST https://shapelid-kernel-production.up.railway.app/analyze \
  -F "file=@part.stl" \
  -F "technology=fdm" \
  -F "material=fdm_pla" \
  -F "quantity=1" \
  -F "mode=simple"
```

### Parameters

<Table>
  | Parameter | Type | Required | Description |
  |-----------|------|----------|-------------|
  | file | file | Yes | CAD file (STL, OBJ, GLTF, STEP, IGES, DXF) |
  | technology | string | Yes | One of: fdm, sla, sls, mjf, dmls, polyjet, cnc_turning, cnc_milling, edm, laser_cutting, bending |
  | material | string | Yes | Material key (e.g., fdm_pla, sla_standard_resin) |
  | quantity | int | No | Number of parts (default: 1) |
  | mode | string | No | "simple" or "advanced" |
  | finish | string | No | Finish option |
  | color | string | No | Color option |
  | resolution | string | No | Resolution/layer height |
  | tolerance | string | No | Tolerance grade |
  | certification | string | No | Certification requirement |
</Table>

## Response

```json
{
  "technology": "fdm",
  "material": "fdm_pla",
  "quantity": 1,
  "volume_cm3": 12.5,
  "surface_area_cm2": 85.3,
  "print_time_min": 42,
  "breakdown": {
    "material_cost": 0.31,
    "machine_cost": 1.40,
    "setup_cost": 2.00,
    "overhead": 0.84,
    "subtotal": 4.55
  },
  "unit_price": 6.32,
  "total_price": 6.32,
  "manual_quote": false,
  "currency": "USD"
}
```

### Manual Quote Response

When a trigger fires, the response includes:

```json
{
  "manual_quote": true,
  "quote_triggers": ["high_quantity", "overhang_ratio"],
  "quote_warnings": ["Quantity exceeds auto-pricing threshold for FDM+TPU"],
  "breakdown": { ... }
}
```
