| Mode | Count | Description |

## Pricing Sources

<Table>
  | Category | Source | Materials |
  |----------|--------|-----------|
  | Non-ferrous metals | metals.dev API | Al, Cu, Ni, Zn, Pb |
  | Steel | Yahoo Finance HRC=F | S235, S355, SS304, SS316, Tool steel |
  | Plastics | Yahoo Finance BZ=F (Brent proxy) | PA12, PA11, Resin, ABS, PC, TPU |
  | Titanium | Manual override | Ti6Al4V, CP Titanium |
</Table>

## Key Format

Material keys use double underscore (`__`) in the database (e.g., `fdm__pla`) but are normalized to single underscore (`_`) in kernel analysis (e.g., `fdm_pla`).

## Daily Auto-Update

95 of 106 materials are updated automatically:
- **metals.dev** — LME metal prices
- **HRC=F** — Hot-rolled coil steel index
- **BZ=F** — Brent crude (plastic proxy with material-based multipliers)
- **TCMB** — Turkish Lira exchange rate

9 materials have no matching source (custom), 2 titanium materials are skipped (manual override required).
