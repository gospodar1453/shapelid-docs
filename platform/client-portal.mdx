The Client Portal (app.shapelid.com) is where customers upload CAD files, get instant pricing, and manage orders.

## Key Features

- **3D Viewer** — STL/OBJ/GLTF rendered with Three.js, STEP/IGES with occt-import-js (client-side, no server cost)
- **Simple & Advanced Modes** — Simple mode shows 17 curated materials; Advanced mode shows all 135+ materials
- **Instant Pricing** — Kernel API calculates cost breakdown in real-time
- **Manual Quote Flow** — Complex geometries trigger RFQ mode with 8 trigger categories
- **Order Tracking** — Production status with stage-by-stage photo updates
- **PayTR Checkout** — Credit card, installment plans, card tokenization
