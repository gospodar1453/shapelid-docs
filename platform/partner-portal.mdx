The Partner Portal (partner.shapelid.com) is the next-generation hub for verified manufacturers.

## Modules

<Table>
  | Module | Phase | Description |
  |--------|-------|-------------|
  | Job Board | Faz-1 | RFQ intake, filtering by capabilities, accept/reject |
  | Quoting | Faz-1 | Cost breakdown with kernel integration, negotiation |
  | Company Profile | Faz-1 | Capabilities, certifications, production gallery |
  | Production Kanban | Faz-2 | Visual tracking: Assigned → Material → Production → Post-Process → QC → Ship |
  | Quality Control | Faz-2 | Digital checklists, measurement entry, inspection reports |
  | Machine Management | Faz-2 | Equipment inventory, material compatibility, capacity calendar |
  | Logistics | Faz-2 | Geliver cargo integration, tracking sync |
  | Financial Dashboard | Faz-3 | Commission tracking, payment history, revenue analytics |
  | e-Fatura | Faz-3 | Nilvera + Paraşüt integration for invoicing |
  | AI Job Matching | Faz-4 | Smart RFQ matching, DfM feedback, auto-scheduling |
</Table>

See the [Partner Portal Roadmap](https://docs.google.com/spreadsheets/d/1344FIXPGLk2bB366rMpbCmzmGB_pe2fs2_4TztYG6bg/edit) for detailed task tracking.
