Shapelid consists of three interconnected applications and a kernel pricing engine.

## Architecture

| Component | URL | Stack |
|-----------|-----|-------|
| Client Portal | app.shapelid.com | Base44 + Three.js |
| Partner Portal | partner.shapelid.com | Base44 |
| Marketing Site | shapelid.com | Wix |
| Kernel API | shapelid-kernel-production.up.railway.app | FastAPI + Trimesh + NumPy |

## Revenue Model

Shapelid operates on a **Manufacturer of Record (MoR)** model:

- Customer pays the full price through PayTR
- Shapelid takes a dynamic commission (18-35%)
- Manufacturer receives the net amount after escrow release
